## The audit finally sees Laravel

A Laravel Inertia app keeps its React under `resources/js` — a directory
shadscan never read. Projects landed on the generic React adapter with most
of the audit silently skipped. 0.3.0 adds a first-class
`laravel-inertia-react` adapter: detection keys on the `@inertiajs/react`
dependency, a Laravel marker (`artisan` or `laravel-vite-plugin`), and a
`resources/js/pages` directory in either casing. Composer `vendor/`
directories stay out of the scan, and `versions` now reports both the
Laravel framework and Inertia versions.

## Two languages, one document

Laravel splits the document between Blade and React: `app.blade.php` owns
the `<html>` element while Inertia's `<Head>` writes the metadata. Rules
now read both sides — language, favicon, and social tags from the Blade
root view as plain text; titles and descriptions from `<Head>` markup;
`resources/views/errors/404.blade.php` or an Inertia error page for
not-found coverage; and Inertia's built-in progress indicator for loading
feedback, failing only when it is disabled with nothing in its place.
Blade-only and Livewire applications get an honest error naming their UI
stack instead of a generic complaint about React.

## Pages become surfaces

The component render graph seeds one surface per Inertia page from its
default export and resolves persistent `Page.layout` wrappers, so anatomy
and navigation rules see every page composed the way it renders. Where page
resolution is customized away from the default glob, the graph records an
explicit boundary reason rather than guessing.

## Burned in before shipping

Before release, the adapter was run against the official
`laravel/react-starter-kit`, the canonical Ping CRM React demo, and a
strict community starter kit. All three detect correctly with
deterministic double-runs — and the one false positive the burn-in
surfaced (an SVG favicon failing the favicon rule) was fixed with
regression coverage before this release.

## One note for JSON consumers

The report schema is now version 6: `framework.adapter` accepts
`laravel-inertia-react`, and `versions` includes `inertia` and `laravel`.
The GitHub Action reads `score` and `grade` and needs no change.
