## Pages Router, covered

Discovery and rules now understand the Pages Router as thoroughly as the App
Router: `_app`, `_document`, route-level loading, error, and not-found
boundaries, metadata, theme, toast, and mounted-component analysis all
participate in the audit, and the web scanner returns complete Pages Router
reports.

## Documentation that leads with the CLI

The docs were rebuilt around how shadscan is actually used: output formats,
category scopes, score thresholds, project paths, agent prompts, and running
it before AI-agent commits.

## Stricter credit, stabler contracts

Command-menu and shortcut findings now require mounted application surfaces
instead of awarding credit for orphaned components, and the exact hotkey
evidence that satisfied a rule is reported. Hosted scan quota consumption
became atomic under a single end-to-end deadline, empty GitHub archives are
classified correctly, and migration and runtime database roles were separated
for least-privilege access.

## Supply-chain hardening

Published source maps no longer contain original TypeScript source, every
privileged GitHub Actions dependency is pinned to an immutable commit, and the
CLI bundles its argument parser so clean installs stop depending on an expired
historical npm signing key — while keeping Node 18 support.
