## Why this could not be a rule

Every other check shadscan makes reads your source. This one cannot.

A sideways-scrolling page is almost never a single wrong class. It is the sum
of a fixed width here, a long unbroken string there, a chart that renders wider
than its container, a negative margin that escapes its parent — none of which
is wrong on its own, and none of which can be added up without a layout engine.
The overflow exists only once a browser has measured the page.

So this is a separate mode rather than a sixty-second rule. `--check-overflow`
takes the URL of an app you are already running — a dev server, a preview
deployment — opens it in isolated Chromium contexts, and fails if the document
scrolls horizontally or is forced to grow a root scrollbar.

```
shadscan --check-overflow http://localhost:3000 --route /docs --route /pricing
```

It checks a narrow phone (320 × 820) and a wide desktop (1440 × 1000), and up
to ten same-origin routes in one run. When it fails, the report names the
elements most likely responsible, bounded so a broken page cannot produce a
thousand lines of blame.

## It does not touch your score

This is deliberate. The static audit is deterministic: the same files always
produce the same number. A browser check is not — it depends on a server being
up, on fonts loading, on a viewport. Folding that into the score would make the
score depend on the weather.

So `--check-overflow` adds no catalog rule, no points, and no grade. It is a
pass-or-fail gate you run alongside the audit, and it keeps operational
failures — the server was not up, Chromium was not installed — distinct from
product failures, so a broken CI runner never masquerades as a broken layout.

## What it costs you

Driving a browser needs a browser. The package now carries `playwright-core`
as a runtime dependency, and the browser binary itself is a separate opt-in
download the CLI tells you how to install.

That dependency is loaded lazily, only when you actually run
`--check-overflow`. If you never use this mode, nothing about your install
behaves differently, and every existing command is unchanged.

## Nothing else moves

The bundled ruleset stays at `2026.08.45`, the rule catalog is the same size,
and the report schema is unchanged. Your score today is your score tomorrow.
