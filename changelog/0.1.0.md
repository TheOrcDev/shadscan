## One command, one answer

`npx @shadscan/cli@0.1.0` audits the current project and scores its UI
fundamentals from 0 to 100: command menus, theme shortcuts, route states,
accessible controls, form feedback, metadata, mobile behavior, and the
composition contracts of shadcn components themselves. The result is
deterministic — the same source produces the same report, byte for byte —
so scores are comparable across machines, teammates, and CI runs. Every
finding carries repository-relative evidence and a suggested fix, and the
rules that cannot be proven statically say so instead of guessing.

## Built for the agent era

The audit is designed to be handed off. After every interactive scan, the
agent handoff is one Enter away — a neutral, paste-ready plan that groups
findings into fix, decide, and verify work items with acceptance criteria
and the exact rescan command. `--apply` launches an installed Claude Code,
Codex CLI, or Grok Build with that plan directly, and the same handoff is
embedded in the tracked issues our GitHub Action maintains.

## Guardrails that hold

`--fail-under` turns the score into a CI gate that cannot be satisfied by a
partial scan. The composite GitHub Action posts the score and category table
to the job summary on every push. `shadscan setup --pre-commit` installs a
version-pinned score floor as a Git hook, and the shadscan-pre-commit agent
skill holds AI agents to the same standard before every commit they make.

## Honest by construction

Shadscan reads source and configuration — nothing else. It does not start
your app, edit files, call an AI model, upload code, or require secrets.
Rules that need a rendered browser to verify report as advisories rather
than pretending certainty, and anatomy rules resolve against the components
your project actually vendors, so your customizations are part of the
contract rather than violations of it.
