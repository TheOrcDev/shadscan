## See the score, then act on it

Local scans now end with a width-aware score bar and an interactive post-scan
menu. From there, `--apply --agent <provider>` validates an installed Claude
Code, Codex CLI, or Grok Build and launches it with a private, neutral
remediation prompt — no copy-paste required. CI and redirected output stay
deterministic and color-free by default.

## Pre-commit gates you can trust

`shadscan setup --pre-commit` (also offered from the post-scan menu) installs
a score gate pinned to the exact shadscan version and your current assessed
score. It safely updates simple POSIX-native hooks, preserves existing
commands, and hands you a manual plan for hook managers, other interpreters,
and complex hooks instead of touching them.

## Deeper, safer analysis

Navigation landmarks are now correlated through a bounded component render
graph that understands route surfaces, repeated instances, child projection,
responsive visibility, and mutually exclusive branches — without executing
application code. Projects mixing App Router and Pages Router are detected and
audited as hybrids, with both root shells and route-boundary families covered.

## Hardened hosting

Hosted TypeScript parsing and rule evaluation moved into disposable,
resource-limited workers that terminate on request abort and receive no
deployment secrets. Each process is bounded to two active scans with a
retryable `SCAN_BUSY` contract, rate limiting is atomic and epoch-based, and
public GitHub archives download without the server token. Reports also became
byte-stable across runtime locales.
