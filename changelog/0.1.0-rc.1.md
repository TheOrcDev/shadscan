## One command, one answer

`npx @shadscan/cli` audits the current project and prints an evidence-backed
score across six weighted categories. The result is deterministic: the same
source produces the same report, byte for byte, so scores are comparable
across runs, machines, and CI.

## Built for handoff

Beyond the human report, `--json` exposes the complete machine-readable audit
and the agent prompt output groups related findings into `fix`, `decide`, and
`verify` work items — including discovered project gates and a version-pinned
rerun command — so an AI coding agent can start from evidence instead of
guesswork.

## Hosted scanning

A hosted scan API audits public GitHub repositories and sanitized snapshots
with authentication, archive extraction limits, source timeouts, and rate
limits. Local scanning stays read-only with no source upload, telemetry,
install scripts, or AI dependencies.

## Fewer false alarms

The rule engine invests heavily in not crying wolf: empty-state checks demand
real query calls or mapped collection data, heading checks treat separate
component returns as exclusive branches, focus checks inspect actual JSX focus
targets, and label checks correlate dynamic `id`/`htmlFor` pairs — among many
other refinements that keep findings trustworthy.
